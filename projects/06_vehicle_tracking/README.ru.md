# Отслеживание автомобилей и анализ транспортного потока

[English](README.md) | [Русский](README.ru.md)

**Тип проекта:** компьютерное зрение / видеоаналитика  
**Технологии:** Python, YOLOv8, ByteTrack, OpenCV, NumPy, Matplotlib

## О проекте

Пайплайн компьютерного зрения для анализа транспортного потока на записанном видео с городской камеры наблюдения. Система обнаруживает автомобили, отслеживает отдельные объекты между кадрами и строит визуализации транспортного потока.

**Входное видео:** [Запись с камеры в Иркутске](https://disk.yandex.ru/i/hjHdsy6pXZMcYA)

## Возможности

- Мультиобъектный трекинг с сохранением ID с помощью ByteTrack.
- Подсчёт автомобилей при пересечении заданной линии.
- Визуализация траекторий объектов.
- Построение тепловой карты плотности движения.
- Изменение визуального состояния/цвета объектов после пересечения линии.
- Разделение логики обработки на объектно-ориентированные компоненты.

## Архитектура

| Компонент | Ответственность |
|---|---|
| `DetectedObject` | Хранит bounding box, центр, цвет и траекторию объекта |
| `TrafficAnalytics` | Отвечает за аналитику трекинга и подсчёт пересечений линии |
| `HeatMapGenerator` | Накапливает положения объектов и формирует тепловую карту |
| `VideoProcessor` | Координирует чтение видео, детекцию и создание результатов |
