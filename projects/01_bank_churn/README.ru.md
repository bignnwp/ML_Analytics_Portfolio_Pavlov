# Прогнозирование оттока клиентов банка

[English](README.md) | [Русский](README.ru.md)

**Тип проекта:** классический ML / бинарная классификация  
**Технологии:** Python, Pandas, scikit-learn, XGBoost, SHAP, Matplotlib, Seaborn

## О проекте

Проект посвящён применению машинного обучения для выявления клиентов банка, которые могут прекратить пользоваться его услугами. Предполагаемый сценарий — помочь отделу удержания приоритизировать клиентов для своевременной коммуникации.

Целевая переменная — `Exited`. Локальный датасет содержит **165 034 строки и 14 столбцов**.

## Задача

Построить модель, оценивающую риск оттока по характеристикам клиента и его счёта. В этой задаче важна полнота (Recall): ошибка False Negative означает, что потенциально уходящий клиент останется незамеченным.

## Этапы работы

1. Разведочный анализ и проверка качества данных.
2. Подготовка числовых и категориальных признаков.
3. Feature Engineering и предобработка.
4. Сравнение Logistic Regression, Decision Tree, Random Forest и XGBoost.
5. Работа с дисбалансом классов с помощью SMOTE.
6. Интерпретация предсказаний с помощью SHAP.

## Заявленный результат

| Модель | Метрика | Результат |
|---|---:|---:|
| Decision Tree + SMOTE | Recall | **0.85** |

Recall выбран приоритетной метрикой, чтобы снижать количество пропущенных случаев оттока. Полная таблица метрик для всех моделей в текущем описании отсутствует; подробности эксперимента следует смотреть в ноутбуке.
