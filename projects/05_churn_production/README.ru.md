# Production-система прогнозирования оттока клиентов

[English](README.md) | [Русский](README.ru.md)

**Тип проекта:** MLOps / промышленное применение машинного обучения  
**Технологии:** Python, scikit-learn / XGBoost, FastAPI, Docker, Pytest

## О проекте

Проект переводит модель прогнозирования оттока клиентов из формата отдельного ноутбука в сервисную структуру приложения. Основной акцент сделан на инженерных компонентах, которые позволяют предоставлять предсказания через API, тестировать приложение и запускать его в контейнере.

## Цель

Создать production-oriented структуру вокруг модели оттока: обучение и сериализация модели, API для получения предсказаний, автоматизированные тесты и контейнеризация.

## Основные компоненты

| Компонент | Назначение |
|---|---|
| Обучение модели | Обучение и сериализация ML-модели |
| FastAPI | Предоставление предсказаний через REST API |
| Pytest | Unit- и integration-тестирование |
| Docker | Упаковка сервиса в контейнер |
| Документация API | Описание доступных endpoint и сценариев использования |

## Какие навыки демонстрирует проект

- Упаковка обученной ML-модели в компонент приложения.
- Предоставление предсказаний через REST API.
- Разделение логики приложения и процесса обучения модели.
- Тестирование API и поведения компонентов модели.
- Контейнеризация сервиса для воспроизводимого окружения запуска.
