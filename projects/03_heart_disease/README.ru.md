# Прогнозирование сердечно-сосудистых заболеваний

[English](README.md) | [Русский](README.ru.md)

**Тип проекта:** классический ML / классификация медицинских данных  
**Технологии:** Python, Pandas, NumPy, scikit-learn, Matplotlib, Seaborn, SHAP

## О проекте

В проекте исследуются модели классификации, которые по измерениям и клиническим характеристикам пациента оценивают, относится ли запись к классу сердечного заболевания.

Локальный датасет содержит **918 строк и 12 столбцов**. Целевая переменная — `HeartDisease`.

## Задача

Построить и оценить классификационный пайплайн для задачи прогнозирования, связанной со здоровьем. Это учебный исследовательский проект, а не медицинский диагностический инструмент.

## Этапы работы

- Разведочный анализ и проверка качества данных.
- Подготовка числовых и категориальных признаков.
- Feature Engineering и масштабирование при необходимости.
- Сравнение Logistic Regression, Random Forest и Gradient Boosting.
- Оценка по Accuracy, Precision, Recall, F1-score и ROC-AUC.
- Использование SHAP для анализа вклада признаков и поведения модели.

## Результаты

В исходном описании проекта указано, что Random Forest показал высокий Recall. Точные значения метрик в README репозитория отсутствуют, поэтому численное значение здесь намеренно не приводится.

Чтобы сделать проект убедительнее для работодателя, добавь полную таблицу метрик на тестовой выборке, confusion matrix и объяснение выбора порога классификации.
