# Определение авторства текстов с помощью символьных n-грамм

[English](README.md) | [Русский](README.ru.md)

**Тип проекта:** обработка естественного языка / классификация текстов  
**Технологии:** Python, Pandas, NumPy, scikit-learn, TF-IDF, Matplotlib, Seaborn

## О проекте

Эксперимент по классификации текстов: модель определяет, кто из шести известных писателей мог написать данный фрагмент. Для выделения стилистических закономерностей используются символьные TF-IDF-признаки.

## Задача

По небольшому фрагменту текста определить один из шести классов авторов. Эксперимент фокусируется на стилистических сигналах — последовательностях символов, а не на семантическом понимании текста.

## Этапы работы

- Подготовка корпуса текстов шести авторов.
- Разбиение исходных произведений на фрагменты по 1 000 символов.
- Извлечение признаков TF-IDF по символьным n-граммам (диапазон 3–5).
- Сравнение LinearSVC, Logistic Regression и Random Forest.
- Оценка по Accuracy, Macro F1, classification report и confusion matrix.
- Анализ ограничений экспериментальной оценки.

## Заявленные результаты

| Модель | Accuracy | Macro F1 |
|---|---:|---:|
| **LinearSVC** | **94,91%** | **94,60%** |
| Logistic Regression | 94,22% | 93,95% |
| Random Forest | 77,18% | 74,44% |

В проведённом эксперименте лучший результат показала LinearSVC.
